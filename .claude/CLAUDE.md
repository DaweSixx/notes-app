# Notes App — Тестовое задание

## Обзор
SPA-приложение для заметок на Nuxt.js 3/4 (Composition API, TypeScript strict). Каждая заметка содержит название и список задач (Todo list). Приложение состоит из 2 страниц.

## Функциональность

### Главная страница
- Список всех заметок с заголовком
- Todo сокращён до нескольких пунктов (без отметок)
- Действия:
  - Создать новую заметку
  - Перейти на редактирование
  - Удалить (с подтверждением)

### Страница редактирования заметки
**Действия с заметкой:**
- Сохранить изменения
- Отменить редактирование (с подтверждением)
- Удалить (с подтверждением)
- Undo (Ctrl+Z)
- Redo (Shift+Ctrl+Z)

**Действия с пунктами Todo:**
- Добавить
- Удалить
- Отредактировать текст
- Отметить как выполненный

## Ограничения

### Запрещено
- UI-библиотеки (Vuetify, PrimeVue, Element и т.п.)
- Библиотеки для undo/redo (например, undo-manager)
- Автоматическая синхронизация стора с хранилищем (pinia-plugin-persistedstate и т.п.)

### Реализовать самостоятельно
- Вёрстка и модальные окна (SCSS/SASS)
- Синхронизация с хранилищем (вручную)
- История изменений (Undo/Redo)

## Семантика истории изменений
- **Непрерывный ввод текста** → одна запись в истории (фиксация по blur или паузе)
- **Отметка чекбокса, добавление/удаление пункта** → отдельные атомарные записи
- Новое изменение после undo очищает redo-ветку
- **Лимит**: 50 шагов (без хранения 50 полных копий)
- История сбрасывается при: сохранении или отмене редактирования

## Хранилище
- Данные переживают перезагрузку страницы
- Запись — не на каждое изменение
- Сохраняемые данные содержат версию схемы
- **Черновики**: незасохранённое редактирование переживает перезагрузку; при возврате предложить восстановить

## Edge Cases (обязательны)
- Прямой переход по URL несуществующей заметки
- Пустое название заметки / пустой текст пункта → осмысленное поведение
- Удаление заметки, открытой на редактирование во второй вкладке → приложение не ломается

## Требования к качеству

### Тестирование
- Unit-тесты (Vitest) на логику истории и стора
- Компонентные тесты не требуются

### UI/UX
- Модальные окна: focus-trap, закрытие по Escape, полная работа с клавиатуры
- Ctrl+Z / Shift+Ctrl+Z работают глобально на странице редактирования
- Не конфликтуют с нативным undo в текстовых полях
- Без алертов — все подтверждения через модальные окна
- Переиспользуемые компоненты должны быть вынесены
- Адаптивная вёрстка, кросс-браузерность

### Архитектура
- Менеджер состояния для хранения информации (Pinia)

## Формат сдачи
- Публичный репозиторий GitHub/GitLab
- Dockerfile и docker-compose.yaml
- `docker-compose up` → работоспособная копия

## Договорённости

### Порядок работы
- Работаем поэтапно: перед этапом — список файлов и что в них будет; файлы этапа создаются только после «меняй».
- Коммиты делает пользователь после каждого этапа.
- Старые `app/pages/index.vue` и `app/components/notes/NoteCard.vue` переписываются на месте под новый дизайн.
- Архитектура простая: базовые папки Nuxt, без FSD.

### Дизайн
- Образец — `design-prototype-v2.html` в корне проекта (держим до конца работы).
- Glassmorphism, фиолетово-розовые градиенты, анимированные цветные пятна на фоне.
- Две темы (светлая/тёмная) с переключателем; по умолчанию — системная, выбор хранится в localStorage.
- Анимации: переходы страниц, hover, появление/удаление элементов, микроанимации; учитывать `prefers-reduced-motion`.
- Адаптив: десктоп + мобильный.
- Иконки (inline SVG), бейджи («Готово», «Черновик»), прогресс-бар на карточках.
- Шрифт Nunito, локальные woff2 в `public/fonts` (кириллица + латиница, вариативный 400–800).

### i18n
- `@nuxtjs/i18n`, языки `ru` и `en`.
- `strategy: 'no_prefix'` — URL не зависят от языка.
- Язык по умолчанию — по языку браузера; если не ru/en — английский.
- Выбор языка сохраняется (cookie `notes-locale`), переключатель RU/EN в шапке.

### План этапов
1. Основа: SPA, SCSS и темы, шрифт, фон, шапка, переключатели темы и языка, i18n
2. Базовые компоненты: иконки, кнопки, чекбокс, прогресс-бар, бейдж, модалка (focus-trap, Escape), тосты
3. Стор и хранилище: Pinia, localStorage с версией схемы, отложенная запись, синхронизация вкладок
4. История undo/redo (composable) + тесты Vitest
5. Главная страница
6. Страница редактирования
7. Черновики и edge-cases
8. Docker и README
